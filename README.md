# Health Reminder

A small browser-based reminder app for building everyday hydration and meal habits. It displays reminders in the page and can send browser notifications when permission is granted.

## Features
- Configurable reminder intervals for drinking water and eating.
- In-page notification list with timestamps.
- Browser Notification API integration.
- Lightweight HTML, CSS and vanilla JavaScript; no build step.

## Files
- `index.html` — page structure and settings controls.
- `script.js` — reminder timing, notification display and interaction logic.
- `style.css`, `styles.css` — styling assets used by the interface.

## Run
Clone the repository and open `index.html` in a modern browser. For the most reliable notification behavior, serve the folder from localhost or HTTPS and allow notifications when prompted.

## Notes
Keep the page open for reminders to run; this is a front-end demo, not a guaranteed background alarm service. Browser support and notification permissions vary by device. The notification icon URLs in the source are placeholders and should be replaced with valid project assets if needed.
